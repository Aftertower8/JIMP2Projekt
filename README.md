# JIMP2Projekt — Graph Visualizer

A Java application with a graphical user interface for visualizing graphs. Developed as a university project to practice Java programming, graph representations, and GUI development.

## Features

- Graph visualization through a graphical interface
- Interactive graph exploration
- Graph representation and manipulation

## Technologies

- Java
- JFrame
- Graph data structures

## Project Status
This project was developed as part of a university coursework assignment.
